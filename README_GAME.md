# أبطال الضرب — نسخة المسابقة الجماعية

واجهة ويب لـ GitHub Pages باستخدام Firebase Authentication (Anonymous) وRealtime Database. ليست جاهزة قبل تفعيل الدخول المجهول ونشر قواعد الأمان واختبار مسابقة من عدة أجهزة. حساب المعلم في هذه النسخة هو هوية مجهولة مرتبطة بمتصفحه، لذلك قد يفقد التحكم في غرفة حال حذف بيانات المتصفح. رمز الغرفة يتيح الاطلاع على أسماء المشاركين ونتائجهم لمن يعرفه؛ استخدم الأسماء الأولى فقط.

## التحضير

1. فعّل مزود Anonymous في Firebase Authentication للمشروع abtal-al-darb-fca9d.
2. انشر محتوى database.rules.json في قواعد Realtime Database بعد المراجعة؛ هذه القواعد تتيح للمستخدمين المجهولين إنشاء الغرف وقراءة الغرفة لمن يعرف رمزها، وتقيّد كتابة نتيجة كل لاعب بهويته.
3. ارفع index.html إلى GitHub Pages ثم افتحه من رابط HTTPS. رابط localhost أو ملف محلي قد يتطلب ضبط Authorized Domains في Firebase Authentication.
4. اختبر إنشاء غرفة وانضمام جهازين وبدء المسابقة وتجميع النقاط وانقطاع الاتصال وإعادة الاتصال.

## قيود مهمة

- لا توجد حماية قوية من الغش: احتساب الإجابة يتم داخل المتصفح، ويمكن للمستخدم المتقدم التلاعب بنتيجته. يلزم خادم موثوق للتحقق من الإجابات إذا كانت النزاهة الصارمة مطلوبة.
- كل من يعرف رمز الغرفة ويسجل دخولًا مجهولًا يستطيع قراءة بيانات الغرفة، وهو ليس كلمة مرور سرية. لا تستخدم أسماء كاملة أو بيانات شخصية.
- يجب الاحتفاظ بصفحة المعلم ومراقبة الإنترنت. لا يوجد استرجاع للغرف من الواجهة بعد العودة للرئيسية.
- البيانات مخزنة حتى تُحذف من Firebase؛ لا توجد إزالة تلقائية في هذه النسخة.
- المزامنة تعتمد على الإنترنت؛ إذا انقطع الاتصال عند الإجابة قد يرفض الحفظ وتظهر رسالة خطأ.
